# План повторного QA-тестирования (Retest)

---

## 1. Импорт Атрибутов (CSV и ZIP)
- [ ] **Экспорт -> Изменение -> Импорт:**
  1. Нажать «Атрибуты ZIP» и скачать архив.
  2. Открыть один CSV из архива, вручную изменить/дописать значения атрибутов (например, `Farbe`, `Breite`).
  3. Загрузить измененный файл через кнопку **«Импорт CSV»**.
  4. **Проверка:** В таблице у этих товаров атрибуты должны сразу обновиться на новые значения.

---

## 2. Стабильность Центра Валидации
- [ ] **Перезагрузка страницы (F5):**
  1. Перейти во вкладку **Валидация**.
  2. Нажать **F5** (перезагрузить страницу).
  3. **Проверка:** Список фабрик с ошибками должен стабильно появляться с первой же перезагрузки без пустых экранов.

---

## 3. Логика AI Attributes (Защита от перезаписи)
- [ ] **Частично заполненный товар:**
  1. Взять товар, у которого уже заполнен хотя бы 1 атрибут (например, `Farbe: Schwarz`).
  2. Запустить для него **AI Attributes**.
  3. **Проверка:** Уже существующее значение `Schwarz` не должно перезаписаться — ИИ заполнит только те поля, которые были пустыми.

---

## 4. Скорость повторной загрузки фабрики (Кэш)
- [ ] **Мгновенный рендер:**
  1. Зайти в фабрику на 500+ товаров (`Timur_for_Otto_Standard_8`).
  2. Вернуться в список фабрик и зайти в нее повторно.
  3. **Проверка:** Таблица товаров должна открыться мгновенно (< 0.1 сек из IndexedDB), без 5–10 секунд ожидания.

---

## 5. Drag-выделение с авто-скроллом
- [ ] **Выделение с прокруткой вниз:**
  1. Зажать левую кнопку мыши на первой строке таблицы.
  2. Потянуть курсор к нижней границе экрана и удерживать.
  3. **Проверка:** Таблица должна сама плавно скроллиться вниз, непрерывно выделяя проезжающие товары.

---

## 6. Синхронизация с OKB (Отсутствующие товары)
- [ ] **Обработка статуса Not Found:**
  1. Выбрать товары, которых нет в OKB (`timur_for_otto_8`).
  2. Нажать «Скачать кэш».
  3. **Проверка:** Прогресс-бар должен дойти до 100% и корректно закрыться с сообщением `Not Found: 33` без зависания интерфейса.
